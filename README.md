# Огородный Замес — Последний урожай

Визуальная новелла на русском языке. Последняя версия включает оригинальную музыку, прозрачные портреты персонажей, Нюру и чёткие фоны.

## Запуск

Откройте `docs/index.html` в браузере или запустите статический сервер из каталога `docs`. Игра работает без установки зависимостей. Сохранения остаются в текущем браузере.

Пробел, Enter или клик по реплике — продолжить; цифры 1–5 — выбрать ответ. Настройки, сохранение, история и тетрадка доступны в меню ☰ справа сверху. Внизу остаются только диалог и ответы.

Перед сменой локации или главы можно подтвердить переход либо остаться: подождать, поговорить с жителями или заняться грядками там, где это уместно. У жителей 15 случайных реплик без повторов до исчерпания списка. Полив, прополка и рыхление дают по +1 к карме, каждый вид ухода — один раз за главу. Карма и занятия сохраняются; старые сохранения совместимы.

Экран загрузки ждёт фон и портреты новой сцены. Если иллюстрация не загрузилась, можно повторить попытку или вернуться в меню.

## Проверки

```sh
node tests/story-check.cjs
node tests/engine-check.cjs
```

## Публикация

GitHub Pages публикует каталог `docs` из ветки `main`. В Settings → Pages выбран источник Deploy from a branch: main /docs. При следующих коммитах сайт обновляется автоматически.

## Структура

- `docs/story.js` — сценарий.
- `docs/game.js` — движок и сохранения.
- `docs/leisure.js` — загрузка сцен, подтверждение переходов, занятия и карма.
- `docs/style.css` — оформление.
- `docs/assets` — иллюстрации и пять оригинальных аудиозаписей.

Мир и замысел — автор проекта «Огородный Замес». Иллюстрации адаптированы из материалов проекта и дополнены для новеллы. Музыка восстановлена без изменения файлов из авторского архива 3D-версии.
